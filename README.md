# 🕵️ Spy Night — React + Firebase

Реальная realtime-версия игры «Шпион» для Discord.

## Что уже работает

- создание комнаты и код;
- вход по коду с разных устройств;
- realtime-лобби;
- случайный шпион;
- секретная роль для каждого игрока;
- случайная локация;
- обсуждение в Discord;
- голосование;
- автоматический результат после голосов всех игроков;
- очки;
- несколько раундов;
- без таймера.

## 1. Установка

Нужен Node.js 18+.

```bash
npm install
npm run dev
```

## 2. Создай Firebase

1. Открой Firebase Console.
2. Создай проект.
3. Добавь Web App.
4. Создай Firestore Database.
5. Скопируй конфиг Web App.

Сделай копию `.env.example` с именем `.env.local` и вставь туда значения:

```env
VITE_FIREBASE_API_KEY=...
VITE_FIREBASE_AUTH_DOMAIN=...
VITE_FIREBASE_PROJECT_ID=...
VITE_FIREBASE_STORAGE_BUCKET=...
VITE_FIREBASE_MESSAGING_SENDER_ID=...
VITE_FIREBASE_APP_ID=...
```

## 3. Firestore Rules

Для демонстрационного MVP в проекте есть `firestore.rules`.

ВАЖНО: эти правила открытые и подходят только для теста/прототипа. Перед настоящим публичным запуском нужно добавить Firebase Authentication и нормальные правила безопасности, чтобы игрок не мог читать чужую секретную роль.

## 4. Запуск

```bash
npm run dev
```

Открой адрес Vite на компьютере. Для проверки с телефона/другого ПК можно использовать деплой на Vercel или другой хостинг.

## 5. Как играть

1. Один человек создаёт комнату.
2. Кидает код в Discord.
3. Остальные заходят по коду.
4. Создатель запускает игру.
5. Каждый видит только свою роль в интерфейсе.
6. Все общаются в Discord.
7. Ведущий переводит игру к голосованию.
8. Все голосуют на сайте.
9. После голосов всех игроков показывается результат.
10. Ведущий запускает следующий раунд.

## Важное замечание

Это рабочий MVP для тестирования механики. Для полноценного публичного ивента перед релизом стоит добавить:
- Firebase Authentication / анонимную авторизацию;
- строгие Firestore Security Rules;
- защиту от повторного голосования;
- корректный серверный подсчёт результатов;
- защиту от читов;
- возможность кикать игроков;
- reconnect после обновления страницы;
- Discord invite/ссылку на войс;
- админ-панель ведущего.
